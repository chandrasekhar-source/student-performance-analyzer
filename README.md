# Student Performance Analyzer

## 📌 Project Overview

This project analyzes student performance using Python, NumPy, and Pandas.

It calculates average marks, identifies student performance categories, and analyzes study hours.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas

## 📂 Project Structure

student-performance-analyzer/
│
├── data/
│   └── students.csv
│
├── src/
│   └── analyzer.py
│
├── README.md
│
└── requirements.txt

## 🚀 Features

- Load student dataset
- Calculate average marks
- Find highest and lowest averages
- Categorize performance
- Analyze study hours
- Handle missing values
- Export analyzed data

## ▶️ How to Run

Install dependencies:

pip install -r requirements.txt

Run the program:

python src/analyzer.py
